## 0. 요약

1. **설정 화면**을 넣었다. 앱을 돌리기 전에 열려서 모니터·해상도·화면 비율·게임 화면 영역을 **자동으로 감지**하고, 사용자는 눈으로 확인만 하면 된다. 설정 파일을 손으로 고칠 일이 없다.
2. 여는 방법 3가지: **첫 실행에 자동으로**, `python -m tft_advisor --setup`, 오버레이 트레이 메뉴 **"설정(화면 자동 감지)…"**.
3. **"자동 감지"** 버튼 하나로 다시 감지한다. 모니터를 전부 한 장씩 찍어 **스테이지 글자(OCR)** 로 채점해 TFT가 떠 있는 모니터를 고르고, 레터박스(검은 띠)를 잘라낸 뒤 그 영역의 비율로 ROI 프로파일을 고른다.
4. **"테스트 캡처"** 버튼: 한 장 찍어 인식하고 **ROI 사각형을 그린 미리보기**와 **항목별 결과표**(화면/스테이지/레벨/골드/상점/체력 …)를 보여 준다. 인식 위치가 맞는지 게임을 켜 둔 채 바로 확인할 수 있다.
5. macOS **화면 기록 권한**: 캡처가 검게 나오면 그것을 감지해 `시스템 설정 → 개인정보 보호 및 보안 → 화면 기록` 경로와 **"권한을 켰다 — 다시 시도"** 버튼을 띄운다.
6. PySide6가 없거나 `--no-overlay`이면 **같은 감지·저장 로직을 콘솔 대화형**으로 쓴다(숫자 메뉴, 테스트 캡처 포함).
7. 저장은 `config/settings.toml`에 **주석·순서를 그대로 두고 값만** 바꾼다. 쓰기 전에 검증하고, 직전 내용을 `settings.toml.bak`으로 백업한다.
8. 테스트 **83개 추가**(`tests/app/test_setup.py`). 전체 **855 passed, 2 failed, 4 skipped, 1 xfailed**. 실패 2건은 이번 작업 전부터 있던 것이다(§8).

## 1. 사용자가 보는 흐름

```
python -m tft_advisor            # 첫 실행 → 설정 화면이 먼저 뜬다 → [저장 후 시작] → 실시간 앱
python -m tft_advisor --setup    # 언제나 설정 화면을 연다
python -m tft_advisor --no-setup # 첫 실행이어도 건너뛴다
```

설정 화면(위에서 아래로):

| 구역 | 내용 |
|------|------|
| 안내 | "TFT를 **테두리 없는 창 모드**로 띄운 뒤 [자동 감지]를 누르세요. 값이 맞으면 [저장 후 시작]만 누르면 됩니다." |
| **🔍 자동 감지** | 큰 파란 버튼. 옆에 상태 한 줄(초록 "TFT 화면을 찾았다" / 주황 "확인하지 못했다 — 값은 추정이다") |
| 감지 결과 | 모니터 · 캡처 크기 · 게임 화면 영역 · 게임 해상도와 비율 · ROI 프로파일(**실측/유도** 표시) · 게임 화면 확인 여부. 경고는 주황, 권한 문제는 빨강 |
| 화면 캡처 권한 | 검은 캡처일 때만 보인다. 경로 안내 + [권한을 켰다 — 다시 시도] |
| 직접 고치기 | 모니터 · 화면 비율 · 게임 해상도 · ROI 프로파일 · 게임 화면 영역 자동/수동(비율 4칸 + [감지한 영역 넣기]) |
| 추천·오버레이 | Jev 판단(mock/live/off) · 오버레이 불투명도 · 글꼴 배율 |
| **📷 테스트 캡처** | ROI를 그린 미리보기 + 12행 결과표(항목 / 인식 결과 / 신뢰도) |
| 버튼 | **저장 후 시작** / **저장만** / **취소** |

창은 열리자마자 픽셀 채점으로 **예비 감지**(즉시)를 하고, 창을 보여 준 직후 인식기(OCR)를 만들어 **확인 감지**(1~3초)를 한 번 더 한다. 그래서 빈 창을 보며 기다리지 않는다.

### 콘솔 대체 UI (`--no-overlay` 또는 PySide6 없음)

같은 감지 결과를 글자로 찍고 숫자 메뉴를 준다:
`[1] 이대로 저장하고 시작 [2] 모니터 다시 고르기 [3] 화면 비율 직접 지정 [4] 다시 감지 [5] 저장만 [6] 테스트 캡처 [0] 취소`

첫 실행 자동 열기는 **대화형 터미널일 때만** 한다(`sys.stdin.isatty()`). 파이프·CI·테스트에서 `input()` 앞에 멈추지 않기 위해서다. `--setup`은 사용자가 직접 부른 것이므로 이 검사를 건너뛴다.

## 2. 감지 규칙

`app/setup.py` `detect(monitors, grab, scorer=, prefer=, content_box_auto=)` — **Qt 없이** 도는 순수 함수라 전부 테스트된다.

1. **모니터 목록** — `mss.monitors`. 0번은 "모든 모니터를 합친 가상 화면"이라 **버리고 1번부터** 물리 모니터만 쓴다. 목록에 하나뿐이면 0번을 쓴다(`vision.capture.MssSource._pick`과 같은 번호 규칙 → `[capture] monitor`에 그대로 넣을 수 있다). `left == 0 and top == 0`이 주 모니터이고, 아무것도 원점에 없으면 첫 번째를 주 모니터로 본다.
2. **배율·이름** — `QApplication`이 이미 있으면 Qt 화면 정보를 얹는다(고DPI 표시용). Qt 좌표는 논리 픽셀이고 배율이 섞인 다중 모니터에서는 **위치를 한 배율로 환산할 수 없다**(3024x1964@2x 옆의 1920x1080@1x → mss `left=3024`, Qt `left=1512`). 그래서 확실한 조건부터 4단계로 맞춘다: 물리 크기+위치 → 논리 크기+위치 → 물리 크기만 → 논리 크기만. 못 찾으면 배율 1.0으로 둔다. **배율·이름은 표시용이고 캡처에는 영향이 없다.**
3. **모니터마다 한 장 캡처 → 채점** — 기본은 픽셀 채점(`vision.capture.default_screen_score`, 즉시), 인식기가 있으면 **스테이지 글자 OCR 채점**(`recognizer.screen_score`). 최고점을 고르고, 동점이면 `[capture] monitor`의 현재 값 > 주 모니터 순. 모두 0점이면 주 모니터.
   - 픽셀 채점은 최댓값이 0.5라 **"찾았다"고 말하지 않는다**(모니터끼리 비교하는 데만 쓴다). OCR 채점이 `GAME_FOUND_SCORE = 0.5`(= `vision.capture.MONITOR_CONFIRMED`) 이상일 때만 "TFT 화면 확인"이다.
   - 한 모니터의 캡처가 실패해도 나머지로 계속한다.
4. **검은 화면** — 평균 밝기 < 6.0이고 최댓값 ≤ 32면 검은 프레임으로 본다. 검은 프레임은 채점하지 않는다. **모든** 모니터가 검으면 권한 문제로 처리한다(§5).
5. **게임 화면 영역(content box)** — `[vision] content_box_auto`가 켜져 있으면 `vision.regions.detect_content_box`로 레터박스/필러박스 **검은 띠만** 잘라낸다. 비율 `(x1, y1, x2, y2)`로 저장하므로 창 크기·DPI가 바뀌어도 유효하다. 예: 1920x1200 모니터의 16:9 게임 → `(0, 0.05, 1, 0.95)`, 게임 해상도 1920x1080.
6. **비율 → ROI 프로파일** — 잘라낸 영역의 비율로 `aspect_name` → `profile_for_frame`. **16:9 · 16:10만 실측**이고(`MEASURED_PROFILES`) 4:3 · 21:9 · 32:9는 16:9에서 유도한 미검증 값이라 경고한다. 지원 목록에 없는 비율은 "캡처 영역이 잘못 잡혔을 수 있다"고 경고한다.
   - 1:1처럼 **16:9에서 ROI를 유도할 수조차 없는** 비율(`derive_profile`이 화면 밖 좌표를 만들어 `ValueError`)은 예외로 죽지 않고 16:9 배치로 대신하며 경고한다. (이번에 고친 크래시 경로.)
7. 감지 전체는 `safe_detect()`로 감싼다 — mss가 아예 없거나 권한이 거부돼도 설정 화면은 뜨고, 실패를 권한 문제로 표시한다.

### 저장할 값으로 옮기기 (`choice_from_detection`)

- 모니터·게임 화면 영역은 **감지값으로 못박는다**.
- 해상도는 감지한 게임 화면 크기(`1920x1200` 등)를 적는다.
- 비율·프로파일은 실측 비율이면 **`"auto"`로 둔다** — auto가 같은 결과를 내고, 나중에 해상도를 바꿔도 따라간다. 실측이 아닌 비율(21:9 등)일 때만 이름을 적는다.
- 콘솔에서 비율을 직접 지정하면 해상도는 `"auto"`로 되돌린다(`resolution`과 `aspect`가 어긋나면 설정 검증이 막는다).

## 3. 저장하는 설정 키

`SetupChoice.updates()` — 설정 화면이 쓰는 키는 이게 전부다. `config/settings.toml`의 주석도 이번에 전부 손봤다(한국어, "설정 화면이 여기에 쓴다"를 명시).

| 섹션 | 키 | 값 | 비고 |
|------|----|----|------|
| `[capture]` | `monitor` | `"auto"` 또는 mss 번호 | 대화상자 "모니터" |
| `[vision]` | `resolution` | `"auto"` / `"1920x1200"` | 감지한 게임 화면 크기 |
| `[vision]` | `aspect` | `"auto"` / `"16:9"` / `"16:10"` / `"4:3"` / `"21:9"` / `"32:9"` | 실측 비율이면 auto |
| `[vision]` | `profile` | `"auto"` / `"set18_16x9"` / `"set18_16x10"` | 고급. auto가 아니면 위 둘보다 우선 |
| `[vision]` | `content_box` | `[x1, y1, x2, y2]` 또는 **없음** | 없으면 그 줄을 주석 처리한다(설명은 남는다) |
| `[vision]` | `content_box_auto` | `true` / `false` | 레터박스 자동 잘라내기 |
| `[advisor]` | `jev_backend` | `"mock"` / `"live"` / `"off"` | **기본 mock** — 켜지 않으면 과금·네트워크 없음 |
| `[overlay]` | `opacity` | 0.2 ~ 1.0 | |
| `[overlay]` | `scale` | 0.5 ~ 3.0 | |

**쓰기 방식**(`save_settings` / `update_toml_text`)
- TOML 원문을 줄 단위로 훑어 **값만** 바꾼다. 주석·키 순서·빈 줄·인라인 주석을 유지한다(문자열·배열 안의 `#`은 주석으로 보지 않는다).
- 섹션에 없던 키는 섹션 끝에, 없던 섹션은 파일 끝에 붙인다.
- 값이 `None`이면 그 줄을 `#`으로 주석 처리한다(설명 겸 예시로 남긴다).
- 쓰기 **전에** 결과 전체를 `Settings.model_validate`로 검증한다. 실패하면 **아무것도 쓰지 않고** 예외를 낸다(깨진 설정으로 앱이 못 뜨는 일을 막는다). 대화상자는 이 실패를 빨간 글씨로 보여 주고 창을 닫지 않는다.
- 덮어쓰기 전에 `config/settings.toml.bak`으로 백업하고, 임시 파일에 쓴 뒤 `replace`로 바꾼다(반쯤 쓰인 파일이 남지 않는다). `.gitignore`에 `config/*.bak`을 넣었다.

**"셋업 완료" 기록** — `_state/setup.json`(gitignore). `completed_at`, 저장한 선택값, 감지 요약이 들어간다. 이 파일이 없으면 첫 실행으로 본다. 파일이 깨져 있어도 첫 실행으로 본다(죽지 않는다).

## 4. 테스트 캡처

`run_test_capture(image, recognizer)` — 프레임 1장 → `Recognizer.recognize` → 한국어 결과표 + `draw_rois`로 ROI를 그린 미리보기. **예외를 내지 않는다**(인식기가 터져도 메시지로 바꾼다).

표에 나오는 12개 항목: 화면 · 스테이지 · 레벨 · 경험치 · 골드 · 연승/연패 · 체력 · 상점 확률 · 상점 5칸 · 아이템 벤치 · 보유 증강 · 증강 후보. 각 행에 `GameState.confidence_of`의 신뢰도를 같이 보여 준다.

메시지 분기:
- 검은 캡처 → "화면이 검게 잡혔다" + 권한 안내(§5).
- 스테이지·레벨·골드가 **모두** None → "게임 HUD를 읽지 못했다 — TFT 게임 중(준비 단계) 화면이 아니거나, 모니터/게임 화면 영역이 잘못 잡혔다."
- 그 밖 → "N/12개 필드를 읽었다 · 인식 123ms".

대화상자는 지금 **위젯에 있는 값**으로(저장 전) 캡처·인식한다. 인식기는 한 번만 만들고 설정만 갈아 끼운다(OCR 모델·템플릿을 다시 싣지 않는다).

## 5. macOS 화면 기록 권한

모든 모니터 캡처가 검으면(또는 캡처 자체가 실패하면) 권한 문제로 보고 이렇게 안내한다:

```
화면이 검게 잡힌다. macOS 화면 기록 권한이 필요하다:
  시스템 설정 → 개인정보 보호 및 보안 → 화면 기록 → 이 앱(터미널 / Python)을 켠다
  → 앱(터미널)을 완전히 종료했다가 다시 실행한 뒤 다시 감지한다.
게임이 전용 전체화면(exclusive fullscreen)이면 테두리 없는 창 모드로 바꾼다.
```

macOS가 아니면 전용 전체화면 안내만 띄운다. 대화상자는 이 안내를 빨간 테두리 그룹으로 보여 주고 **[권한을 켰다 — 다시 시도]** 버튼을 단다(같은 프로세스에서 다시 감지한다 — 권한을 켠 뒤 앱을 재시작해야 할 수도 있다고 안내문에 적었다). 콘솔은 같은 글을 찍고 `[4] 다시 감지`를 쓰면 된다.

**오버레이에서 연 설정은 다시 시작해야 적용된다.** 실시간 루프의 인식기·캡처 소스는 시작할 때 만들어지기 때문이다. 저장하면 상태 줄과 트레이 알림으로 "앱을 다시 시작하면 적용된다"고 알린다. 대화상자가 떠 있는 동안에는 오버레이 창을 숨긴다(테스트 캡처에 오버레이가 찍히지 않도록).

4. `safe_detect` — 감지 실패가 콘솔 설정에서 역추적을 뱉던 문제.
5. `wants_setup` — 비대화형에서 첫 실행 자동 열기가 `input()` 앞에 멈추던 문제(기존 `tests/app/test_cli.py::test_main_routes_to_live_with_flags`가 이 때문에 깨졌었다 → 지금은 통과).
