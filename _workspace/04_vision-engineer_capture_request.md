# 게임 화면 캡처 요청서

작성: vision-engineer / 2026-09-22 (QA 04 반영 개정판)

**왜 필요한가요?** 지금 가진 예시 화면 7장은 방송 화면을 캡처한 것입니다. 채팅창과 방송 장식이 섞여 있고 크기도 제각각이라서, 프로그램이 화면의 어느 위치를 읽을지 정확히 맞출 수 없습니다. 게임 화면을 직접 찍은 원본이 있으면 위치를 맞추고, 얼마나 정확하게 읽는지 측정하고, 아이템 그림도 실제 화면 기준으로 새로 만들 수 있습니다.

**하실 일은 세 가지입니다.**
1. 아래 1절대로 설정을 확인합니다.
2. 2절의 화면을 찍어서 폴더 하나에 모읍니다.
3. 4절의 질문에 짧게 답합니다.

정답 파일(JSON)은 직접 쓰지 않으셔도 됩니다. 스크린샷만 주시면 Claude가 초안을 만들고, 틀린 값만 고쳐 주시면 됩니다(3절).

### 찍는 방법

- **1순위: `Win` + `PrtSc`** (Windows 키를 누른 채 PrtSc).
  화면이 한 번 살짝 어두워졌다 돌아오면 저장된 것입니다. 파일은 **`사진` → `스크린샷`** 폴더에 PNG로 자동 저장됩니다.
- 쓰지 말아 주세요.
  - **`PrtSc`만 누르기**: Windows 11에서는 부분 캡처 도구가 열립니다. 화면 일부만 잘리거나 저장이 안 될 수 있어요.
  - `Win` + `Shift` + `S` (부분 캡처)
  - 카카오톡·디스코드로 보낸 파일 (화질이 떨어집니다), 방송 화면 캡처
- 게임 스크린샷 키(`F12`)를 쓰셔도 됩니다. 저장 위치는 보통 `C:\Riot Games\League of Legends\Screenshots`입니다.
  **파일 이름이 `.jpg`로 끝나면 쓰지 말고** `Win` + `PrtSc`로 다시 찍어 주세요(JPG는 화질이 손상됩니다).
- **확인**: 파일을 마우스 오른쪽 클릭 → 속성 → 자세히 → 크기가 **1920 x 1080**(또는 알려 주신 해상도)이면 됩니다.

### 파일을 모으는 곳

- 폴더 하나에 모아서 전달해 주세요. 프로젝트 안에 넣으신다면 `tests\fixtures\screens\raw\` 폴더입니다.
  **이 폴더는 아직 없으니 새로 만들어 주세요.**
- 파일 이름은 `스테이지_화면.png` 형식이면 좋습니다(예: `3-2_준비.png`, `2-1_증강.png`, `3-4_캐러셀.png`). 헷갈리면 그냥 두셔도 됩니다.
- **주의**: 화면 오른쪽 플레이어 목록에 **다른 사람들의 소환사 이름**이 찍힙니다. 이 캡처를 공개 저장소(GitHub 공개 등)에 올리지 말아 주세요.

## 4. 질문 (짧게 답해 주세요)

1. **연패 아이콘**: 연승일 때는 골드 오른쪽에 주황 불꽃 아이콘이 보이고, 연승이 0일 때는 파란 물방울 아이콘이 보였습니다. **연패일 때는 아이콘이 어떻게 생겼나요?** (2절 #8 캡처가 있으면 그걸로 확인하겠습니다.)
2. **"2-4 아이템선택" 예시 화면**: 가운데 원형 트랙에서 아이템을 든 유닛들이 돌고 있어서 **캐러셀(공동 선택)** 로 보입니다. 파일 이름의 "아이템선택"이 캐러셀을 뜻한 게 맞나요? 아니면 이번 시즌에 따로 있는 아이템 선택 화면인가요? (따로 있다면 #13을 부탁드립니다.)
3. **연승·연패 숫자를 추천에 쓸지**: 지금은 **연승이나 연패가 1 이상이면 그 숫자를 추천에 쓰지 않습니다.** 연승인지 연패인지를 아이콘 색으로 짐작하는데, 연패 화면을 아직 한 번도 못 봐서 틀릴 수 있기 때문입니다. 연승·연패가 0일 때는 그대로 씁니다. #8 캡처로 연패 아이콘을 확인하면 그때부터 쓰겠습니다. 이렇게 해도 될까요? (상점 확률과 체력은 이미 추천에 씁니다.)
4. 왼쪽 아이템 첫 칸의 **작은 숫자**(예시 화면에서 4, 5, 7)는 자석 제거기의 **남은 사용 횟수**인가요? 아니면 같은 아이템이 여러 개 겹쳐 있다는 뜻인가요?
5. 인게임 HUD 크기를 기본값에서 바꿔 쓰시나요?

## 부록 A. 정답 파일 형식 (직접 쓰실 때만)

스크린샷과 같은 이름으로 `.expected.json`을 만듭니다(예: `3-2_준비.png` → `3-2_준비.expected.json`).

```json
{
  "_note": "원본 1920x1080, 테두리 없음, HUD 기본, 한국어",
  "screen_mode": "planning",
  "stage": "3-2",
  "level": 6,
  "xp": [4, 36],
  "gold": 42,
  "streak": -2,
  "hp": 71,
  "shop_odds": [30, 40, 25, 5, 0],
  "shop": [
    {"name": "카르마"},
    {"name": "니달리"},
    null,
    {"name": "라칸"},
    {"special": "3단계와 함께", "cost": 9}
  ],
  "item_bench": ["자석 제거기", "B.F. 대검", "연습용 장갑", "고속 연사포", null, null, null, null, null, null],
  "augment_offer": ["고위천사의 지팡이", "출정", "수완가"]
}
```

- 모르거나 안 보이는 항목은 **줄을 통째로 빼 주세요.**
- `screen_mode`: `planning`(준비) / `combat`(전투) / `augment_select`(증강 선택) / `carousel`(캐러셀) / `item_select` / `loading` / `game_over`
- `streak`: 연승 `+N`, 연패 `-N`, 없으면 `0`
- `shop`: 왼쪽부터 5칸. 빈칸은 `null`. 특수 상품은 `{"special": 이름, "cost": 가격}`
- `item_bench`: 왼쪽 세로 아이템 칸을 **위에서부터 10칸** 순서대로, 게임에 보이는 한국어 이름으로. 빈칸은 `null`.
- 짐작한 값에는 `"note_필드이름": "이유"`를 함께 적어 주세요(예: `"note_level": "채팅에 가려 짐작"`).

## 부록 B. 개발자 메모 (사용자는 읽지 않아도 됩니다)

- **item_bench 라벨 = 한국어 표시 이름**으로 통일했다. `harvest-items`가 정적 데이터로 apiName(묶음 대표 ID)으로 바꾸고, 못 바꾸는 이름은 저장하지 않고 오류로 보고한다(QA04-V1 수정). 라벨에 apiName을 써도 받는다. `note_item_bench` 키도 임시로 읽는다.
- `fixtures.py`(app-integrator, Phase 3 config round에서 반영): `items` 이름 → 대표 ID ItemRef, `item_bench` → `ExpectedScreen.extras["item_bench"]`(대표 ID|None). `items`가 없으면 item_bench로 채워 정확도 비교 대상이 된다. 대표 ID(`ItemCatalog.resolve`)를 쓰므로 자석 제거기도 vision 출력(`DA_Consumable_ItemRemover`)과 ID로 바로 같다.
- 평가 경로: `evaluate.py`와 `test_vision.py` fixture 테스트는 `tests/fixtures/screens/*.expected.json`만 본다(`raw/` 하위는 보지 않음). 원본 캡처는 `python -m tft_advisor.vision.evaluate tests/fixtures/screens/raw`로 따로 평가하고, 라벨이 확정되면 방송 크롭 대신 `screens/`로 옮길지 결정한다.
- 원본 캡처와 `items_screen/` 템플릿은 Riot 아트워크 + 타 플레이어 이름이 있으므로 공개 저장소에 올리지 않는다(`data/templates/README.md`).
- 캡처 순서 제안: #1 → #4(harvest) → #5 → #8 → #7 → 나머지.
